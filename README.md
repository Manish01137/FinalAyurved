# FinalAyurved

**Aksharam Ayurved** — Authentic Panchakarma &amp; Ayurvedic Hospital Website

A static marketing site for an Ayurveda &amp; Panchakarma clinic in Ahmedabad, built with hand-written HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` — Home (hero, services overview, special programs, testimonials, FAQ)
- `about.html` — About Vaidya Dolly Solanki Makwana &amp; clinic story
- `service.html` — Full treatment catalogue (55+ Ayurvedic therapies, filterable gallery)
- `blog.html` — The Aksharam Journal (landing page with featured + 6 articles)
- `blog-1.html` — `blog-7.html` — Individual blog posts on Panchakarma, Shirodhara, Doshas, PCOS, Garbhadhana Sanskar, Seasonal Cleansing, Localized Bastis
- `contact.html` — Contact form &amp; appointment booking

## Tech

- **HTML5 + CSS3** — pure static, no build tools
- **Vanilla JavaScript** — navbar interactions, FAQ accordion, treatment-gallery filter
- **Google Fonts** — Playfair Display (headings) + Inter (body)
- **Font Awesome 6.5** — iconography

## Asset folders

- `images/` — original site images (logo, hero, individual treatment thumbnails)
- `Ayurveda Photo/` — 58 branded therapy photos used across the service page &amp; blog

## Local preview

Open any HTML file directly in a browser, or serve the folder with any static-file server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
